## 👤 About

I'm **Allan Vitor**, an Information Management graduate (Federal University of Pernambuco — UFPE) currently pursuing a second degree in Information Security. I interned at **Dell Technologies** in a corporate security environment, working with security operations, access management and governance.

My edge is the **developer background**: I don't just run security tools, I understand and build them. This blog is where I turn study into applied practice — offensive labs, defensive analysis, and security tooling written from a builder's perspective.

**Focus:** offensive security (pentesting) with a solid grounding in defensive fundamentals.
